# MA Strategy Validation on 500 PNG Images

Status: completed, 500 images and 3,000 official pixel checks passed. Production
encoding defaults are unchanged.

This extends [the shallow-plan and warm-start experiment](MA_WARM_START_EXPERIMENT_20261109.md)
to exactly 500 distinct PNG source files. It evaluates the existing native Rust
experiments; it does not introduce a new routing policy or change the codec.

## Scope and Sampling

`tools/select_ma_corpus.py` selects from the archived full-corpus manifest,
using seed `20261109`, source-directory strata and balanced source subgroups.
Selection does not use candidate compression results. The previous 11 MA test
images are pinned; the other 489 are outside that small matrix, not necessarily
unseen in earlier encoder development. Exact duplicate source files, APNG and
invalid PNG framing are excluded before freezing the manifest. Encoding failures
after that point are retained; they do not cause replacement sampling.

| Stratum | Images |
| --- | ---: |
| High-resolution photographs (DIV2K) | 80 |
| Other photographs | 60 |
| Urban scenes and buildings | 40 |
| Manga | 40 |
| Mixed local samples | 40 |
| Documents and web screenshots | 60 |
| Game and UI screenshots | 40 |
| Alpha images and icons | 50 |
| Textures | 40 |
| PNG format and mixed-content samples | 50 |
| Total | 500 |

The frozen selection contains 1,170,283,172 pixels, 40 sixteen-bit PNGs and
22 packed one/two/four-bit PNGs. Original image dimensions are retained,
including the 8100 x 11708 document. These are deliberately diverse strata,
not prevalence weights for a particular application's workload.

## Method

- Windows x86-64, Ryzen 9 7945HX; eight encoder threads, one trial per variant.
- Six variants: baseline, fast-basic, fast-full, seed-only, seed-refine and
  seed-repair. All use effort 9; seed depth is 3. Variant order rotates by image.
- Baseline is the existing Rust direct native candidate, not the outer
  multi-candidate scheduler or official C++ encoding.
- Frozen binary: `out/ma-seed-20261109/encoder-lab.exe`, SHA256
  `e612367bf619d6da7271ab69e032c9855a7216c922c80ebe9766ac90bccf0005`.
- Official `djxl` 0.12.0 (`a1ebdf2`) decodes every output. Pixel samples must
  match the original PNG, including hidden RGB, alpha and sixteen-bit values.
  Equality of compressed JXL bytes is not an acceptance criterion.
- Metadata-free temporary input snapshots isolate pixel encoding. Packed PNGs
  are expanded losslessly; snapshot pixels are checked against original pixels
  before encoding. The baseline is re-run on the same snapshot, so comparisons
  do not mix the previous small matrix's input preprocessing with this run.
- Native `seconds` includes analysis, sample preparation, training and encoding.
  It excludes process startup, PNG input decoding, output I/O and validation.
  Subprocess wall time is recorded separately, not used as encoding time.
- Images and variants run serially to avoid concurrent benchmark workloads.
  Encoded JXL and decoded PNG outputs are temporary and removed after checking.
- A 600-second subprocess watchdog records a failure, not a successful fast
  fallback. Failed cases remain in the selected denominator.

Comparisons require successful baseline and candidate trials on identical
snapshot pixels. Aggregate bpp is `8 * total_bytes / total_pixels`, and aggregate
MPix/s is `total_pixels / 1e6 / total_encode_seconds`. Per-image medians, strata,
byte-weighted totals and large regressions are reported separately. A single
pass is broad screening evidence, not statistical proof of small timing gains.

Zero-work experimental receipts are reported as bypasses only when all counters
are consistently idle and original-pixel validation still succeeds. They must
not be counted as evidence that a shallow or seeded tree was actually exercised.

## Reproduction and Artifacts

The ignored local artifact directory is `out/ma-corpus500-20261109/`:

- `sample.json`: frozen source identities, dimensions, strata and selection log.
- `run/run.json`: binary, manifest, script hashes and configuration.
- `run/trials.jsonl`: durable per-variant measurements, receipts and failures.
- `run/progress.json`: current phase and completed counts.
- `run/report.json`: final execution status and cleanup status.
- `run/analysis/SUMMARY.md`: overall, stratum and previous-case comparisons.
- `run/analysis/summary.json`: machine-readable aggregates and failed records.
- `run/analysis/regressions.json`: matched per-image results and worst cases.

Run from the repository root with a built experimental `encoder_lab` and an
independent official `djxl`; replace the executable placeholders below:

```text
python -B tools/benchmark_ma_corpus.py --encoder path/to/encoder_lab --decoder path/to/djxl --manifest out/ma-corpus500-20261109/sample.json --out out/ma-corpus500-20261109/run --effort 9 --threads 8 --timeout 600
python -B tools/summarize_ma_corpus.py --manifest out/ma-corpus500-20261109/sample.json --trials out/ma-corpus500-20261109/run/trials.jsonl --out out/ma-corpus500-20261109/run/analysis
```

The runner requires a new output directory. Add `--resume` with the same command
to resume an existing run; changed binaries, scripts, manifest or configuration
are rejected. A `STOP` file in the run directory requests stopping after the
active case; remove it before resuming. Completed failures are not silently
retried. A changed original source invalidates that case's recorded trials.

## Results

All 500 images completed all six variants: 3,000/3,000 successful encodes and
official-decoder pixel checks, zero timeouts, zero source-integrity failures,
zero experimental receipt bypasses. All temporary output directories were
removed. The full harness took 5,179.101 seconds (86 minutes 19 seconds), including
input preparation, six variants, official decoding and original-pixel checking.
Four source-profile warnings from libpng did not prevent pixel verification;
metadata fidelity is outside this pixel-only experiment.

Focused tooling tests: 3 sampler, 16 runner, 15 summary and 18 shared canonical
input tests passed (52 total). No new native build, full-workspace regression,
JPEG, multiframe, floating-point or Linux runtime test is claimed here.

The shallow variants trade considerable compression ratio for speed. Refine
and Repair usually find slightly smaller files, but total savings are only
636,808 and 709,386 bytes respectively across the entire sample. The small
single-pass timing differences are not evidence of statistically significant
speed gains or losses.

confusing these with multi-megabyte increases in the shallow routes.

Textures are the strongest positive aggregate result: Full reduced size on
22/40 images, for example `rough_linen_Diffuse_1k.png` from 4,808,033 to
4,626,191 bytes (-3.782%) and 1.0760 to 0.3720 seconds. However, 17/40 texture
images grew by more than 0.25%, including 10 by more than 5%; this is not a safe
blanket texture rule. None of the 180 images in the two photo strata and Urban
became smaller with Full.

Outside the prior 11-image MA matrix, the other 489 images show Full at
+5.85% bytes / -25.80% time, Refine at -0.082% / -1.43%, and Repair at
-0.090% / +3.07%. The same qualitative result holds without the known cases.

### Important Counterexamples

- `Graveyard_27x39_ENGLISH.png` (94,834,800 pixels): baseline 42,928,156 bytes,
  39.370 s, 3.62130 bpp, 2.40882 MPix/s. Full uses 50,515,084 bytes (+17.674%)
  and 34.872 s. Refine uses 42,967,812 bytes and 38.419 s. Repair saves only
  565 bytes while taking 41.406 s. None is an attractive replacement here.
- `7006.png` (plot): Full grows 17,850 -> 33,128 bytes (+85.591%) while slowing
  0.1771 -> 0.4018 s. A simple-looking graphic is not enough to admit this route.
- `img_480x360_3x16bit_RGB_grid_triangle_a_0080x0060_1.png`: Full grows
  814 -> 2,216 bytes (+172.236%); Seed Only grows to 2,351 bytes (+188.821%).
  Refine and Repair recover 782 and 804 bytes. All outputs remain pixel exact.
- `ReveryEarth.png`: Refine records 0.9496 -> 8.6024 s for a 0.326% size
  reduction. Repair records 0.8257 s on this image. This isolated single-pass
  timing anomaly is preserved, not discarded or asserted to be reproducible;
  repeat timing and profiling would be needed to attribute the cause.

## Decision

Keep the experimental options, but do not replace the production e9 strategy.
Full predictor statistics are a useful optional fast route for some content;
they are not a generally better MA learner. Shallow seeds followed by ordinary
refinement retain most of the search cost and provide very small aggregate
size gains here. Repair is not worth enabling globally on this evidence.

The positive texture cases justify a targeted future experiment, not a route
selected by testing all six candidates at runtime. This sweep did not validate
an inexpensive admission rule or low-effort replacement. All source dimensions
were retained, no failures were replaced, and no additional encoding reruns
were appended to improve the reported results.
